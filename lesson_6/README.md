## Занятие 6. Массивы
**Условие:** Имеется массив действительных чисел. Заменить все нулевые элементы средним значением. Поместить в другой массив все ненулевые элементы. Сравнить средние значения обоих массивов.
**Тесты:** * Ввод: `5` элементов (`1 0 3 0 6`) 
* Вывод: Среднее исходного `2`, измененный массив `1 2 3 2 6`, второй массив `1 3 6`, среднее второго `3.33`.

## Занятие 6. Строки
**Условие:** Дан текст. Подсчитать сколько раз в нем встречается определенное слово.
**Тесты:**
* Текст: `Кот сидел на крыше. Рядом прошел еще один кот.`
* Искомое слово: `кот`
* Вывод: `2 раз(а)`.
