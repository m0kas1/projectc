# Практические работы по C++

**Выполнил:** Ефимов Сергей
**Вариант:** 11

Данный репозиторий содержит решения практических задач по программированию на C++. 
Проект разделен на папки по темам занятий. Подробные условия задач, результаты тестирования и скриншоты находятся в файлах `README.md` внутри каждой соответствующей директории.

## Структура проекта

### [Занятие 3: Логические выражения](./lesson_3)
* **Файл:** `lesson3.cpp`
* **Описание:** Программа вычисляет значение логического выражения, определяя, попадает ли точка с заданными координатами (x, y) в заштрихованную область (квадрат или треугольник). 
* В папке также находится скриншот графика искомой области из Desmos (`image.png`).

### [Занятие 6: Обработка массивов и строк](./lesson_6)
* **Файл 1:** `array_task.cpp` (Массивы)
  * **Описание:** Замена нулевых элементов массива на среднее значение, формирование нового массива из ненулевых элементов и сравнение их средних значений. Работа выполнена с использованием динамических массивов (коллекции не применялись).
* **Файл 2:** `string_task.cpp` (Строки)
  * **Описание:** Подсчет количества вхождений заданного слова в текст. Реализовано с помощью базовых методов класса `string` (`find`, `length`) без использования сторонних библиотек для парсинга.
