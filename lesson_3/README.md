## Занятие 3. Логические выражения
**Условие:** Составить логическое выражение, принимающее значение истина, если точка с координатами [x,y] является внутренней точкой квадрата с вершинами {[1,1], [0,1], [0,0],[1,0]} или треугольника с вершинами {[2,0],[2,2],[4,0]}.
**Тесты:**
1. Ввод: `0.5 0.5` -> Вывод: `1`
2. Ввод: `3 0.5` -> Вывод: `1`
3. Ввод: `1 2` -> Вывод: `0`
4. Ввод: `2.5 1.5` -> Вывод: `1`
5. Ввод: `4 2` -> Вывод: `0`
6. Ввод: `0.5 2` -> Вывод: `0`
