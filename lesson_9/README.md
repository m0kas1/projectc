# Работа со структурами и файлами (Занятие 9-10). Вариант 11.

## Условие задачи
**Часть 1 (Структуры):**
Определить комбинированный (структурный) тип для представления анкеты ребенка, состоящей из его имени, пола, роста, даты рождения. 
1. Ввести информацию по 20 детям. 
2. Вывести средний рост 12-летних девочек. 
3. Перенести в отдельный массив 3 самых младших мальчиков. 
4. Отсортировать список учеников по дате рождения. 
5. Вывести все данные по конкретному ученику (по фамилии ученика). 
6. Реализовать функцию изменения данных конкретного ученика. 
7. В отдельный массив поместить список детей, имеющих день рождения в заданном месяце. Реализовать вывод отфильтрованных данных в виде оберточной функции. 
*Требования: использовать функции, enum, вложенные структуры, сортировку пузырьком.*

**Часть 2 (Файлы):**
1. Считать из текстового файла данные числового поля (пол: 0 — мужской, 1 — женский). Если фамилия совпадает с очередным элементом массива структур, то в поле записывается соответствующее значение из файла.
2. Сделать чтение / запись своей структуры в бинарный файл. Оформить в виде подпрограмм.
